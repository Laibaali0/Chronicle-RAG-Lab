# Changelog

## 0.1.0 — initial reference implementation

- Version/date-scoped document retrieval and JSONL ingestion.
- BM25, hashed lexical similarity, reciprocal-rank-fusion baselines.
- SQLite persistence, dataset digests, deterministic extractive answers and citation checks.
- Optional OpenAI-compatible completion adapter (not enabled by default).
- Local FastAPI service, cache, process-local rate limit, CLI commands.
- Synthetic labeled retrieval benchmark with precision, recall, MRR, nDCG and paired bootstrap.
- Tests for version boundaries, prompt framing, API responses, persistence and evaluation.

All benchmark fixtures and code examples are synthetic educational material.
